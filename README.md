# Veritas Autos

Professional static marketplace front end for Veritas Autos.

## Included

- Real vehicle hero treatment
- Automotive product catalogue layout
- Engine and mechanical parts
- Braking
- Electrical
- Suspension and steering
- Body parts
- Accessories
- Tyres and rims
- Truck and commercial parts
- Passenger vehicle and truck matching
- Mercedes Benz, HOWO, MACK and DAF vehicle coverage
- Vehicle model lists linked to the selected make
- Vehicle years from 2000 through the current year
- Responsive desktop and mobile layout

## Note

This is the front end foundation. Marketplace search, catalogue data, accounts, cart, checkout, vendor management and compatibility rules will connect to the Laravel and MySQL backend in the production build.
